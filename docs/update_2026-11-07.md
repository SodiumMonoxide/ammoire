# AMMoire 0.2.0 更新与验收

本轮从此前 AMMoire 0.1.0 发布副本续接，综合随后两轮 NiCl₂ 转角工作和 11/07 模型日报，形成独立可运行的 0.2.0 发布仓库。原研究目录保留。GitHub 上传由用户的本地 dsh 接力。

## 已完成的更新

| 更新 | 具体行为与来源 |
|---|---|
| 显式公度电子 TB | `CommensurateTriangularBilayer` 支持此前已核验的八组 `(m,n)`：0、13.17、21.79、27.80、32.20、38.21、46.83、60°，每层 7/13/19 位点，对应 28/52/76 维；保留原 0° 同面积对照。 |
| 转角比较口径 | 示例分别导出固定 `ka=0.45` 与固定 `0.8|ΓM|`；`primitive_dispersion` 与折叠最低能量秩分列，复现零层间跃迁下的折叠反号控制。 |
| Cairo 微观输入 | `make_model('cairo', delta=...)` 为第 25 个原生预设。两磁性、四非磁性轨道与物理自旋；原文 S5–S7 的 d=0 矩阵转换为周期 Bloch 规范。能量为论文 `|t|` 单位，`j=JS`。可用统一接口作为连续模型单层输入。 |
| 数值缺陷修复 | `resolve_bands` 原先默认 `np.allclose` 会接受反厄米残差 9×10⁻⁶ 的矩阵。现在分别校验 H/Q 的有限值和明确厄米容差，接受的浮点舍入噪声显式对称化；不再沿用默认相对容差。 |
| 研究证据与文献 | [14 篇精选](literature/selected_papers.md)和 JSON 记录发表状态、既有/新增及阅读深度；修正三项旧署名。新增只指相对所查记录未命中的 CrO 与纹理锁定两篇预印本。 |

原有 24 个模型、HAM 守恒诊断、平面波 `MoireBilayer`、VASP/Wannier90 接口保留。`legacy.daily_model` 继续作为可选的外部旧日报适配器；原生模型与新增算例没有本机目录依赖。

## 中间转角工作怎样纳入

[转角研究说明](twist_history.md)将材料归档与本轮代码计算分开标注。除多角几何外，关键继承是：同物理动量不等于同折叠带身份；27.80° 折叠最高占据支的 −14.527 meV 与同原胞 Q 扇区的 +64.873 meV 是不同配对。磁序稳定性也须独立于固定交换场电子谱判断。

此前 27.80° 直接展开、21.79° 收敛表、静态磁矩与单层自旋螺旋的派生数据归入 [历史基准](../benchmark/twist_history/README.md)。本轮重算放在 `benchmark/commensurate/`、`benchmark/cairo/`。本轮没有重跑 VASP、材料波函数展开或磁序搜索；21.79° 缺可用探针波函数这一跨角比较限制仍然存在。

## 验收结果

详细记录见 [release_checks.json](../validation/release_checks.json)。本机 Python 3.12.14、NumPy 2.3.5；可选图使用已有 Matplotlib，发布仓库不携带第三方库。

- **24 项 unittest 通过**：原 6 项、公度 10 项、Cairo 4 项、矩阵校验回归 4 项。涵盖全部 25 个原生预设、倒格周期、节点、C₂ 换自旋、C₃、互补角、零交换/零耦合极限、i 波六阶与 Cairo 应变四阶→二阶。
- **独立打包安装通过**：构建 0.2.0 wheel，用 `pip --target` 安装在源码之外；从该安装运行全部测试、连续莫尔/Cairo/公度示例以及 VASP/Wannier90 合成解析自测。未借助旧日报路径。
- **历史数值复核通过**：新八角表与旧表的共同能量列最大差 `8.89e-13 meV`；同 Q 折叠对照表最大差 `2.23e-12 meV`。Cairo 在三种应变、71 个随机 k 上，与日报 d=0 原矩阵的逐项残差为零。
- **示例与图通过**：21.79° 最低支近 Γ 幂指数约 5.9913；Cairo 第五支两点有效幂指数约 3.9797/1.9593。CSV 及 PNG 随基准保存，图件已检查。
- **远端检查**：GitHub Actions 工作流已增加两种新示例；远端执行结果须在 dsh 上传后查看。本机仅验证 Python 3.12，CI 将检查 Linux 3.10 与 Windows 3.12。

## 复用示例

```python
import numpy as np
from ammoire import CommensurateTriangularBilayer, make_model

angle27 = CommensurateTriangularBilayer(m=5, n=2)
k = np.array([0.2, 0.1])  # Cartesian, inverse monolayer a
h = angle27.hamiltonian(k)
spin_energies = angle27.spin_bands(k)  # (..., up/down, ascending rank)
primitive_lower = angle27.primitive_dispersion(k, layer=0)
cairo = make_model('cairo', delta=0.1)  # paper |t| units
```

公度参数是既有 Ni 单轨道几何演示，尚非 Ni/Cl 多轨道拟合。仅支持八组已核验整数胞；无 SOC、磁序与结构固定。Cairo 的 Bloch 规范变换须同步用于外部轨道算符和层间矩阵。WSe₂ 四层模型、自洽磁序形成和材料拓扑候选列入后续扩展，未计作本轮新功能。
