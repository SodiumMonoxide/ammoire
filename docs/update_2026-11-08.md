# AMMoire 0.3.0 更新与验收

2026-11-08 的 WSL 接口验收和后续转角多材料研究带来三项更新。

- Wannier90 seed 导入从 `.win` 获取晶胞，并按默认的轨道对 Wigner–Seitz 修正重建周期哈密顿量。`wannier_validate` 与同一 seed 的参考能带比较，输出 RMSE、最大差和倒格周期残差。[VASP 与 Wannier90 工作流](vasp_wannier.md)
- 共线 DFT 探针检查由显式的晶胞和笛卡尔操作配对，分别报告占据谱、全谱、节点与选定能量秩的劈裂。已有材料数据回放复现了三组配对及七个探针的历史结果。材料原始数据归入独立研究备份，发布仓库提供合成回归。[共线谱用法](collinear_symmetry.md)
- `CompensatedTriangularBilayer` 复用八组公度三角几何。每个母层含两个相反交换场的子层，支持独立关闭界面跃迁、均匀界面势和配准势。模型参数用于比较机制，材料的定量尺度由 DFT 或 Wannier 拟合确定。[Sheoran 与 Bhattacharya 的材料计算](https://doi.org/10.1103/PhysRevMaterials.8.L051401) · [Liu 等的亚层势机制](https://doi.org/10.1103/ln1f-9x8r)

## 补偿母层的界面控制

补偿模型每子层一个三角网，单轨道基底按下至上的四个子层排列，每位点交错放置物理自旋上、下。各母层的子层偏移为 \(\pm(a_1+a_2)/3\)，交换场沿子层依次取 \((-J,+J,-J,+J)\)。每子层 7、13 或 19 个位点，矩阵分别为 56、104 或 152 维。实空间以母层晶格常数 \(a\) 为单位，笛卡尔动量以 \(1/a\) 为单位，能量为 eV。

界面项由面对面的子层间高斯跃迁与同一配准核产生的在位势组成。在位势的层内平均值和零平均的空间调制可以分别缩放。关闭两种界面项后，独立母层的相反自旋谱重合。转角下可逐项加入界面耦合，核对哪一项产生劈裂。靠近同自旋简并点时，按能量排序的最低支应结合下一带间隙解读。

```python
from ammoire import CompensatedTriangularBilayer

isolated = CompensatedTriangularBilayer(m=2, n=1, interlayer=0, facing_potential=0)
hopping_only = CompensatedTriangularBilayer(m=2, n=1, facing_potential=0)
uniform_only = CompensatedTriangularBilayer(m=2, n=1, interlayer=0, registry_scale=0)
registry_only = CompensatedTriangularBilayer(m=2, n=1, interlayer=0, uniform_scale=0)
k = [0.30, 0.10]  # Cartesian, 1/a
for model in (isolated, hopping_only, uniform_only, registry_only):
    print(model.splitting(k)[0])  # lowest within-spin energy rank, up minus down in eV
```

## 本轮验证

40 项测试通过，覆盖原有公度与连续模型、新补偿母层、共线谱伙伴、Wannier90 距离修正和参考路径误差。补偿模型回放了八角七种界面开关的 56 组结果。共线谱入口用真实七点计算产物回放，输出与历史分析吻合。

真实 MoS₂ 非 SOC 和 SOC 验证均从此前 VASP 导出矩阵开始，仅重跑独立 Wannier90。两个 29 点的参考路径最大差分别为 0.01030 和 0.01425 meV，均小于 0.02 meV。真实算例核验了导入和插值。材料 TB 的精度由后续独立 DFT 点、轨道权重及自旋劈裂验证。[验证记录](../validation/release_checks_0.3.0.json)

0.2.0 的 NiCl₂ 历史证据、Cairo 和公度几何保存在同一版本树。发布目录采用独立的 0.3.0 副本，供 dsh 根据既有 `ammoire` 远端历史提交。[此前的转角研究](twist_history.md)
